# NHSP invoice reversal evidence — implementation and TEST verification

## Outcome

The missing NHSP reversal evidence has been fixed and proven against the deployed TEST stack.

A new TEST draft invoice (`1003138`) was generated from an authorised NHSP correction pair. Its two-page PDF contains the same authoritative NHSP source twice on the support page, with the two distinct roles:

- `NHSP Corrected Hours`
- `NHSP Reversal`

The invoice was left as a DRAFT so the deployed result remains available for independent inspection. It was not issued, emailed, or paid.

## Root cause

Invoice generation previously reduced authoritative support evidence to distinct source-row keys. A changed-hours replacement and its reversal deliberately refer to the same NHSP source row, so that reduction collapsed the two correction roles into one support row. A separate `reversal_row_keys` set then marked the surviving row as reversed, while the PDF template did not render that state as an explicit role.

This was a support-evidence presentation defect. The correction pair, signed invoice lines, totals, VAT, and outstanding amount were already correct.
