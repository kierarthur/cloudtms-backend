## Findings and closure

1. **P1, corrected: a failed readback erased the original pending request.** Original `send()` cleared pending on every structured error with outcome_unknown=false, including read-only errors. Worker readback failure describes the query's outcome, not whether the earlier mutation committed. Saved `send()` now clears pending only for a definitive non-readback mutation refusal. Failed readback retains original bytes for Try again.

2. **P1, corrected: committed CLEAR could not recover after reopen.** Original `boundArgs` required a retained CLEAR's snooze_id to equal the fresh active context ID. After a successful CLEAR with a lost response, that fresh ID is null. Saved retained mode permits the original ID/version under the same namespace, while new CLEAR still binds the current native snooze ID. MANY retained mode also preserves the original immutable approved revision after a later approval change, so native original body/page readback remains reachable and native per-line stale/refused processing remains the authority.

3. **P1, corrected: a definitive page error caused an automatic retry loop.** Original save/retry finally blocks unconditionally advanced an incomplete operation when pending was null. A definitive cursor refusal or storage failure therefore queued the same failing page indefinitely. Saved advancement is gated by pageAdopted, set only after a validated page is successfully adopted. All errors stop until explicit user action; successful pages alone continue the visible finite operation.

4. **P2, corrected: revisiting results restored old failures after a successful retry.** Original oldPage readback displayed immutable normal-page rows, losing later retry outcomes once a page left the three-page memory cache or the window reopened. Saved `latestRows` reapplies the native receipt for each actually retried visible line, verifies its request/line and approved-line identity, and retains at most three visible result-page blocks in memory. Successful retried lines no longer regain a Retry control from the old normal page. CLEAR_MANY failures now say Not unsnoozed rather than incorrectly saying Not snoozed.

5. **P2, corrected: exact immutable single-target journal binding.** Saved `boundArgs` now binds scope_kind, canonical snooze_kind, exact Case/component IDs and Work segment/expense component keys to the native context, in addition to Candidate/Work. Historical receipt recovery retains original operands and does not substitute fresh identities into pending bytes. The saved final correction was independently reread. The retry outcome overlay now also applies this bounded native target check before accepting a persisted receipt for a visible line.
