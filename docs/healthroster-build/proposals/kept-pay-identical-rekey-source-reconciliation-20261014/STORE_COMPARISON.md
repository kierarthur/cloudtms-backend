Proposed store is exactly public.weekly_source_kept_as_paid_decisions, IMMUTABLE_APPEND_ONLY, owned by the logical repository owner through the existing release owner adapter. Its fields are id (uuid PK), work_event_id (required FK weekly_work_events, restrict), decision (required CHECK KEEP_AS_PAID), reason (required CREDITED or NOT_INVOICED_DISAPPEARED), credit_invoice_line_id (invoice_lines FK, restrict), facts_fingerprint (required bytea32), actor_user_id (required tms_users FK, restrict), created_at_utc (required server transaction timestamp). CREDITED requires a credit line; NOT_INVOICED_DISAPPEARED requires NULL. The unique expression is (work_event_id,reason,coalesce(credit_invoice_line_id,zero UUID),facts_fingerprint), exactly as §6.2. No separate idempotency key, entitlement bundle, task, economic ledger or process store is introduced.

The one-time migration enables RLS and the existing provider-neutral cloudtms_miget_service_owner_all policy for the adapted owner and service_role. Browser roles and PUBLIC have no table/column privileges. The public service RPC is the write entry; owner-private helpers have service_role EXECUTE revoked. UPDATE/DELETE and TRUNCATE use the existing complete immutable-record guard, and the final public-table contract adds exactly this relation as IMMUTABLE_APPEND_ONLY. Immediate root ACL reassertion is required, rather than waiting for a later global registry. Direct effective/column ACL, policies, FKs/checks/index, immutable first use, service/browser role and PostgREST cache/API-path verification remain required.

Resume means rereading the same canonical facts helper: the most recent matching decision is applicable only while its fingerprint equals the current one. A new covering export, actual changed pay-head movement or any new/deleted genuine linked credit can make the prior acknowledgement inapplicable. Old records remain immutable audit evidence. No runtime delete, cleanup, history rewrite or expiry is proposed. Retaining an acknowledgement never blocks a later Accept source through the genuine existing entitlement proposal/publication owners.
