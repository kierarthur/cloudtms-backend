## Zero raw delta counterexample and proposed coverage

Two held rows each have net100p. Raw VAT30p and10p (gross130p and110p) sum to40p, equal S09 total target40p: original D0. Later mixed choices produce admitted VAT20p+10p=30p (needs D+10p) or30p+20p=50p (needs D−10p). A zero original delta therefore does not prove that no ROUND authority will be needed after a required post-final release. Adding a new movement after the original manifest was frozen would invalidate its immutable census, so it is not proposed.

The proposed FIN delta emits the one existing approved ROUND authority movement even when raw D0 ONLY when that exact frozen membership contains unresolved actual VAT_FIT rows. It freezes raw target/census and pending row IDs before the manifest. D0/no-hold remains no ROUND movement/line, including Report210825. Source/rules flags OFF and old NULL/NHSP paths remain unchanged.

If admitted D is nonzero, the genuine ROUND authority produces the required visible rounding line. If admitted D0, retain a genuine internal zero invoice line, presentation, CURRENT binding and placement so every native census/cardinality check remains intact. The immutable presentation model/FINAL_ISSUE snapshot records an explicit qualified suppression witness and excludes ONLY that exact zero ROUND authority from visible PDF/model lines. Qualification checks actual invoice/line/current binding, approved ROUND origin, all money/pay/net0, original source/hash/census, exact receipt-set authority/SHA and explicit suppression flag. A claimed suppression with no valid witness fails model creation. Ordinary zero lines are unaffected. This is an explicit provenance-bearing internal authority, not an unqualified silently printed zero row.

This operational variant is NOT accepted yet.
