Proposed name for review: private.timesheet_correction_a0_transaction_fences. This names a possible schema only; no migration/DDL has been authored or installed. It is an owner-private concurrency object, never a Checklist/U3 process store, pricing input, business history or evidence authority.

Proposed columns are token_kind, uuid_identity, text_identity and touch_bit. token_kind has the closed domains FAMILY_UUID, PHYSICAL_UUID, BOOKING, KEY_NORM, ALIAS_JSON_STRING. Exactly one identity column is populated and kinds have fixed UUID/text affinity. UUID equality uses actual PostgreSQL uuid values. Booking equality uses the existing0519 btrim result and its actual native text collation. KEY_NORM equality uses the actual tsfin_load_context_batch key comparison/column collation. ALIAS_JSON_STRING equality follows native JSON string containment and must be kept separate from text-collation equality. The unique arbiters must be independently sealed for those domains; do not assume one C/default text index reproduces both native comparisons. No non-NULL/empty-string rule may be invented: SQL NULL contributes no raw equality token, while an empty but non-NULL native identity must retain its existing equality behavior. No hashes/truncation/new normalization are proposed as substitutes for native identity. Native text-length/index limits and nondeterministic collation must be resolved before code acceptance.

The row contains no business actor, request state, price, amount, signed status, readiness, economic fingerprint, parent relation or business timestamp. touch_bit is a private serialization bit: each acquisition changes it, forcing a real tuple update. It is not read by any business owner or exposed to callers. The table has no FK and no immutable/lifecycle business guard. No trigger may suppress its physical UPDATE. It is not cleared/deleted to release a transaction. Runtime retention/space management would require its own reviewed protocol; deletion is not part of this design or this task.

SEND's bounded membership must come from its actual admitted native chain/original facts: the immutable native root; original/reversed physical UUIDs; any actual owner-allocated replacement and reversal UUIDs before their transition; original/reversed/replacement native bookings; and the native original/reversed/replacement occupant key in both KEY_NORM and ALIAS_JSON_STRING domains. Capture the exact ordered native token set for qualification; token membership does not replace full family/source/nativeclock membership.
