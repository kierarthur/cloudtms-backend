# D10 issued-invoice query extension

Source draft; no installation or activation. Source family `13102026_1205_healthroster_issued_signed_query_v1.sql` copies the complete current Import Review catalogue and existing consolidated query enqueue owners. Only their email-evidence call sites delegate to one purpose-bound owner-private helper. Validation and materialisation retain the original evidence function, including every invoice blocker.

The helper returns the original evidence unchanged unless an enabled signed check-only preset, a current unrevoked Timesheet, complete signed Timesheet evidence, exact verified READY Timesheet document, one original issued non-credit invoice and its exact verified READY FINAL_ISSUE document are proved. The HealthRoster import must be later than issue. Electronic records reuse the correction lane's immutable worker/manager witness; QR records retain the existing complete signed-QR contract. Raw manual-PDF signed admission still needs its separate verified legacy witness; it is not inferred here. Weekly client identity resolves through the actual Contract; nullable-Contract DAILY resolves the single current Timesheet-version financial client's identity. Any frozen settings-authority client conflict fails closed. No nonexistent Timesheet client column is assumed.

Only EMAIL_ISSUE/EMAIL_REMINDER catalogue rows receive purpose-bound attachment evidence. The enqueue owner re-resolves it from the stored selected action set and exact committed operation. Existing `hr_issue_emails`, delivery history, deterministic outbox keys, reminders and `mail_outbox` remain the owners. The original invoice, lines, locks, signature and finance have no write path in the added helper. Ordinary, draft, unsigned, disabled and incomplete branches retain the legacy evidence unchanged. No correction is mandatory.

Dependencies: F1 `private.weekly_source_signed_check_only_v1(uuid)` and the credit/request lane's `private.timesheet_correction_signed_witness_v1(uuid,boolean)`. No end-user command or activation is published before those actual compatible owners and the document/security gates pass.

Remaining proofs: real TEST catalogue selection/apply, first query and explicit reminder, exact immutable invoice/T0/lock comparison, direct service/browser negatives, missing/stale document and draft negatives, legacy manual signed witness, and safe mail delivery. No safe agency-owned fixture recipient is verified, so delivery remains BLOCKED; any acceptance enqueue must be rollback-contained or safely held before a mail scheduler can claim it. Source checks and compilation are not these acceptance proofs.
